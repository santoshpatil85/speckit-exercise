# Data Model: MVP RSS Reader

## Feed Subscription

Represents one feed address saved by the local reader.

| Field | Meaning | Validation |
|---|---|---|
| `id` | Stable identity for this subscription | Generated by the application; unique |
| `feed_url` | Submitted address, retained for display and later reference | Trim surrounding whitespace; valid HTTP or HTTPS URL with host and default port |
| `normalized_url` | Comparison value used to identify duplicate subscriptions | Normalize surrounding whitespace and scheme/host case; unique; do not change path or query semantics |
| `title` | Descriptive feed title when supplied by the feed | Optional; treat as untrusted display text |
| `created_at` | Time the subscription was accepted | Required; stored consistently in UTC |

### Relationships

The MVP has one local reader and no account entity. Each feed subscription is independent.
Feed items are not persisted.

### Validation and state

1. A submitted address is pending validation and is not yet a subscription.
2. The application rejects invalid schemes, credentials, non-default ports, unsafe destination
   addresses, network errors, unsuccessful HTTP status, oversized responses, and documents
   that are not valid RSS or Atom.
3. Only a successfully retrieved and parsed feed becomes a saved subscription.
4. A normalized URL already present in storage is a duplicate; it does not create another
   subscription.
5. A saved subscription remains available after application restart.

No separate pending/error entity is persisted; validation errors are returned to the current
reader interaction.
